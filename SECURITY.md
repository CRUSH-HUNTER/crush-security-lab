# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

### How to Report

- **Email:** [mformetanoiawhitehathacker@gmail.com]


### Guidelines

- Do not open a public issue for security vulnerabilities
- Provide detailed information about the vulnerability
- Allow reasonable time for response and resolution
- Do not exploit the vulnerability beyond what is necessary to demonstrate it

### Scope

This repository contains educational security research and documentation. The vulnerabilities documented here are from:
- **OWASP Juice Shop** - Intentionally vulnerable application
- **PortSwigger Labs** - Practice environments

### Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial Assessment:** Within 1 week
- **Resolution:** Depends on severity

## Disclosure Policy

I follow responsible disclosure principles. All findings are documented for educational purposes only.
