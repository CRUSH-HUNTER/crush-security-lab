چالش قفل APT — تشخیص، دلیل، و رفع کامل

مستندسازی کامل مشکل Could not get lock /var/lib/dpkg/lock که در حین نصب ابزارها روی Kali Linux رخ داد — با دلایل دقیق و روش رفع قدم‌به‌قدم.

1

خطاهایی که دریافت شد

Error Messages Encountered
ERROR #1 — apt lists lock

خطای اول — قفل لیست‌های APT

sudo apt update
Error: Could not get lock /var/lib/apt/lists/lock. It is held by process 100256 (apt)
Notice: Be aware that removing the lock file is not a solution and may break your system.
Error: Unable to lock directory /var/lib/apt/lists/
ERROR #2 — dpkg lock

خطای دوم — قفل dpkg (هنگام نصب git)

sudo apt install git -y
Waiting for cache lock: Could not get lock /var/lib/dpkg/lock. It is held by process 106123 (apt)
ERROR #3 — dpkg lock-frontend

خطای سوم — قفل frontend (هنگام نصب sqlitebrowser)

sudo apt install sqlitebrowser -y
Waiting for cache lock: Could not get lock /var/lib/dpkg/lock-frontend.
It is held by process 110724 (apt)
2

چرا این اتفاق می‌افته؟

Root Cause Analysis

مکانیزم قفل در APT/dpkg

لینوکس برای جلوگیری از تداخل بین چند نصب همزمان، از فایل‌های قفل (lock file) استفاده می‌کنه. وقتی یه پروسه‌ی apt داره اجرا می‌شه، این فایل‌ها رو می‌گیره و هیچ apt دیگه‌ای نمی‌تونه اجرا بشه:

/var/lib/apt/lists/lock       ← قفل لیست پکیج‌ها (هنگام apt update)
/var/lib/dpkg/lock            ← قفل دیتابیس dpkg
/var/lib/dpkg/lock-frontend   ← قفل رابط dpkg
/var/cache/apt/archives/lock  ← قفل کش دانلودها

علت‌های رایج ایجاد قفل معلق

علت ۱ — Ctrl+Z اشتباه

زدن Ctrl+Z پروسه رو pause می‌کنه (نه kill) — قفل هنوز گرفته‌ست.

علت ۲ — بسته شدن ترمینال

اگه ترمینال وسط نصب بسته بشه، پروسه ممکنه orphan بمونه.

علت ۳ — آپدیت خودکار پس‌زمینه

سرویس unattended-upgrades در پس‌زمینه داره آپدیت می‌کنه.

علت ۴ — crash ناگهانی

قطع برق یا crash سیستم وسط نصب → فایل قفل پاک نشده.

در این جلسه: دستور apt install sqlitebrowser با Ctrl+Z پس‌زمینه رفت و به‌صورت پروسه‌ی Stopped (T) معلق موند — قفل dpkg رو نگه داشت و هر apt بعدی بلاک شد.

تشخیص — پیدا کردن پروسه‌ی مقصر

این دستور نشون می‌ده کدوم پروسه داره از apt استفاده می‌کنه:

ps aux | grep apt

خروجی در این جلسه:

mary   110724  pts/9   T+   0:03  apt install sqlitebrowser -y
#                              ↑
#                         T = Stopped (pause شده با Ctrl+Z)

وضعیت T در ستون STATUS یعنی پروسه pause شده — نه تموم شده، نه در حال اجرا. هنوز قفل رو گرفته.

3

رفع کامل — قدم‌به‌قدم

Complete Fix — Step by Step
1

پیدا کردن PID پروسه‌ی مقصر

از خروجی ps aux | grep apt یا مستقیم از پیام خطا، عدد PID رو پیدا کن (مثلاً 110724).

ps aux | grep apt
2

کشتن پروسه‌ی مقصر

با -9 (SIGKILL) مطمئن می‌شیم پروسه واقعاً کشته می‌شه و نه فقط pause:

sudo kill -9 110724
3

پاک کردن تمام فایل‌های قفل

بعد از کشتن پروسه، فایل‌های قفل باقی‌مانده رو پاک کن:

sudo rm -f /var/lib/dpkg/lock
sudo rm -f /var/lib/dpkg/lock-frontend
sudo rm -f /var/lib/apt/lists/lock
sudo rm -f /var/cache/apt/archives/lock
4

تعمیر dpkg

اگه نصب ناتموم مونده باشه، این دستور وضعیت dpkg رو به حالت سالم برمی‌گردونه:

sudo dpkg --configure -a
5

اجرای دوباره‌ی دستور اصلی

حالا می‌تونی هر دستور apt رو بزنی:

sudo apt update
sudo apt install git -y
# یا هر پکیج دیگه‌ای
نکته مهم: هیچ‌وقت فایل‌های قفل رو بدون کشتن پروسه‌ی مقصر پاک نکن — ممکنه دیتابیس dpkg خراب بشه. همیشه اول kill، بعد rm.
4

وقایع این جلسه — timeline

Session Incident Timeline
INCIDENT 1

قفل هنگام نصب sqlitebrowser

هنگام نصب sqlitebrowser، پروسه با Ctrl+Z pause شد و به حالت Stopped (T) رفت. قفل /var/lib/dpkg/lock-frontend رو نگه داشت.

Waiting for cache lock: Could not get lock /var/lib/dpkg/lock-frontend.
It is held by process 110724 (apt)
WORKAROUND

دانلود مستقیم با wget (بدون apt)

برای دور زدن مشکل قفل، تلاش شد dbeaver-ce مستقیم با wget دانلود بشه — ولی این هم با مشکل DNS مواجه شد:

wget https://dbeaver.io/files/dbeaver-ce_latest_amd64.deb
Resolving dbeaver.io... failed: Temporary failure in name resolution.
# علت: دسترسی مسدود از ایران + VPN فعال نبود روی wget
RESOLVED

رفع قفل و نصب موفق sqlitebrowser

با اجرای دستورات به ترتیب صحیح، قفل رفع و sqlitebrowser با موفقیت نصب شد:

sudo kill -9 110724
sudo rm -f /var/lib/dpkg/lock /var/lib/dpkg/lock-frontend
sudo rm -f /var/lib/apt/lists/lock /var/cache/apt/archives/lock
sudo dpkg --configure -a
sudo apt update && sudo apt install sqlitebrowser -y
# ✓ نصب موفق

Quick Reference Card

// وقتی apt قفل بود — این دستورها رو به ترتیب بزن

پیدا کردن PID ps aux | grep apt
کشتن پروسه sudo kill -9 <PID>
پاک کردن قفل dpkg sudo rm -f /var/lib/dpkg/lock /var/lib/dpkg/lock-frontend
پاک کردن قفل apt sudo rm -f /var/lib/apt/lists/lock /var/cache/apt/archives/lock
تعمیر dpkg sudo dpkg --configure -a
آپدیت و نصب sudo apt update && sudo apt install <package> -y
بررسی وضعیت پروسه T = Stopped | R = Running | S = Sleeping | Z = Zombie
نکته‌ی مهم برای جلوگیری از تکرار: هیچ‌وقت توی وسط یه apt install از Ctrl+Z استفاده نکن. اگه خواستی متوقفش کنی، از Ctrl+C استفاده کن که پروسه رو کامل kill می‌کنه و قفل آزاد می‌شه.
