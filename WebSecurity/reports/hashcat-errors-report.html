🧨 گزارش چالش‌ها و ارورهای Hashcat

همه‌ی مشکلات، خطاها و تلاش‌های انجام‌شده برای کرک هش رمز عبور

🎯 ۱. هدف

هدف اصلی، کرک کردن هش رمز عبور ادمین بود که از دیتابیس استخراج شده بود:

0192023a7bbd73250516f069df18b500

برای این کار از ابزار hashcat استفاده شد، اما در این مسیر با چندین چالش و ارور مواجه شدیم که در ادامه مستند شده‌اند.

📥 ۲. چالش اول: مشکل نصب Hashcat

۱

دستور اولیه:

sudo apt install hashcat -y
۲

ارور دریافت‌شده:

❌ 403 Forbidden
Failed to fetch https://http.kali.org/kali/pool/main/h/hashcat/hashcat-data_7.1.2%2bds1-4_all.deb Temporary failure resolving 'http.kali.org'
۳

علت: سرورهای پیش‌فرض کالی (http.kali.org) در دسترس نبودند.

۴

راه‌حل: تغییر ریپازیتوری به archive.kali.org

# nano /etc/apt/sources.list deb http://archive.kali.org/kali kali-rolling main non-free contrib deb-src http://archive.kali.org/kali kali-rolling main non-free contrib
sudo apt update sudo apt install hashcat -y
✅ نتیجه: hashcat با موفقیت نصب شد.

🖥️ ۳. چالش دوم: خطای GPU و حافظه

۱

دستور اجرا شده:

hashcat -m 0 -a 0 admin.hash /usr/share/wordlists/rockyou.txt
۲

ارور دریافت‌شده:

❌ Not enough allocatable device memory
Watchdog: Temperature abort trigger set to 90c Initializing backend runtime for device #1. Please be patient... * Device #1: Not enough allocatable device memory or free host memory for mapping.
۳

علت: hashcat تلاش کرد از GPU استفاده کند، اما حافظه‌ی کافی در دسترس نبود.

۴

تلاش برای رفع:

  • استفاده از پارامتر --force برای اجبار به اجرا
  • استفاده از پارامتر -D 1 برای استفاده از CPU به‌جای GPU
hashcat -m 0 -a 0 admin.hash /usr/share/wordlists/rockyou.txt --force -D 1
⚠️ نتیجه: با این تغییرات، hashcat اجرا شد اما همچنان با مشکل حافظه مواجه بود و به‌درستی کار نکرد.

💥 ۴. چالش سوم: خطای Segmentation Fault

۱

دستور اجرا شده:

hashcat -m 0 -a 3 admin.hash ?l?l?l?l?l?l --force

این دستور برای حمله‌ی Brute-Force با ۶ حرف کوچک استفاده شد.

۲

ارور دریافت‌شده:

❌ Segmentation Fault
zsh: segmentation fault hashcat -m 0 -a 3 admin.hash ?l?l?l?l?l?l --force
۳

علت: بار سنگین محاسباتی Brute-Force (همه‌ی حالت‌های ۶ حرفی) باعث کرش hashcat شد.

۴

تلاش برای رفع:

  • استفاده از دیکشنری کوچک‌تر (به‌جای rockyou.txt)
  • استفاده از حالت بهینه‌شده (-O)
hashcat -m 0 -a 0 admin.hash small.txt --force -O

اما همچنان با محدودیت حافظه مواجه بود.

⚠️ نتیجه: hashcat به دلیل محدودیت‌های سخت‌افزاری (حافظه و GPU) نتوانست اجرا شود و از روش جایگزین استفاده گردید.

📥 ۵. چالش چهارم: خطای ۴۰۴ در دانلود مستقیم

۱

دستور اجرا شده:

wget https://github.com/hashcat/hashcat/releases/latest/download/hashcat.zip
۲

ارور دریافت‌شده:

❌ 404 Not Found
HTTP request sent, awaiting response... 404 Not Found
۳

علت: لینک مستقیم دانلود از گیت‌هاب تغییر کرده بود یا فایل در آن آدرس وجود نداشت.

۴

راه‌حل: استفاده از روش جایگزین (CrackStation) برای کرک هش.

  • رفتن به سایت https://crackstation.net
  • چسباندن هش و دریافت نتیجه
✅ نتیجه: رمز عبور admin123 با موفقیت پیدا شد.
